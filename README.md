# Supermarket Loyalty Program: Business Value & Investment Analysis

### MSBA 502 Analytics Programming | University of San Diego

## Project Overview

This project evaluates whether supermarket loyalty membership is associated with meaningful differences in customer spending and whether those differences justify additional investment in loyalty program expansion.

Using 1,000 supermarket transactions, we apply exploratory data analysis, statistical hypothesis testing, multiple linear regression, and hypothetical financial scenario modeling to assess purchasing behavior and potential business implications.

**Key Finding:** Loyalty members spend approximately 9.6% more per transaction than nonmembers. However, the difference is not statistically significant at the 5% level, and the estimated advantage decreases after controlling for other purchasing characteristics.

Our analysis highlights an important business distinction: **higher observed customer spending does not necessarily translate into incremental profitability.**

The project concludes by evaluating potential investment risks and recommending a measured, evidence-based approach to loyalty program expansion.
